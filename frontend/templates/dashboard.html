Our Mission

This application was built with 8 deliberate security flaws so you can practice identifying, exploiting, and remediating real-world vulnerabilities in a safe, controlled environment. Explore the source code, try the exploits below, and then patch each one yourself.

Vulnerabilities to Discover

SQLi

SQL Injection

Login and signup build SQL queries via string concatenation. Try bypassing authentication with a crafted username.

XSS

Stored XSS

Your username is reflected here without escaping. Register a username containing a script payload and see what happens.

XSS

Reflected XSS

The /search endpoint reflects your query directly into the page. Try injecting a script via the q parameter.

Session

Session Hijacking

The session signing key is hardcoded in source. Inspect your session cookie and consider what that means.

Crypto

Weak Password Storage

Passwords are hashed with unsalted MD5. Download the database and see how easily hashes can be reversed.

Exposed

Exposed Database

The full SQLite database is downloadable with no authentication at all. Find the endpoint.

Brute

No Rate Limiting

Nothing throttles login attempts. Consider what an automated script could do here.

CSRF

CSRF

No form on this site carries a CSRF token. A malicious page could submit these forms on your behalf.
